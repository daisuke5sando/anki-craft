# 暗記クラフト

ブラウザで動く暗記ゲーム。問題に正解すると素材が手に入り、素材を集めるとアイテムをクラフトできる。

## 遊び方

1. トップ画面でテスト範囲を選ぶ
2. 科目・カテゴリを選び、「めくり」（カードをめくって自己判定）か「4択」でスタート
3. 正解すると、そのカテゴリの素材が1つ手に入る。間違えた問題は少し後に出直す
4. 同じカードに2回連続で正解すると「覚えた」になる
5. 素材が揃ったらクラフト画面へ。仕上げ問題3問に全部正解するとアイテムが完成し、図鑑に登録される

進捗・素材・図鑑は、遊んでいるブラウザの中（localStorage）に保存される。端末やブラウザを変えると記録はリセットされる。

## 構成

- `index.html` / `style.css` / `app.js` — ゲーム本体（エンジン）。通常は触らない
- `data/index.json` — テスト範囲の一覧
- `data/<範囲ID>.json` — 範囲ごとのカード・素材・レシピのデータ

## 新しいテスト範囲の追加方法

1. `data/` に新しい範囲の JSON ファイルを1つ追加する
2. `data/index.json` に、その範囲の `{id, title, subjects, totalCards}` を1件追加する
3. push すると GitHub Pages に自動で反映される。過去の範囲のファイルはそのまま残る

## データ形式（範囲ファイル）

```json
{
  "id": "2026-11-chukan",
  "title": "2026年11月 中間テスト",
  "subjects": [
    { "name": "数学", "categories": [
      { "id": "m-hirei", "name": "比例",
        "material": { "name": "板材", "icon": "🪵" },
        "cards": [ { "id": "m-hirei-01", "q": "比例の式は？", "a": "y = a x" } ] }
    ] }
  ],
  "recipes": [
    { "item": "木のドア", "icon": "🚪", "needs": { "m-hirei": 6 } }
  ]
}
```

- カードは `q`（問題）と `a`（答え）のペアのみ。4択の選択肢は同じカテゴリの答えから自動生成される
- `needs` は「カテゴリID: 必要な素材数」。レシピは範囲ごとに自由に変えられる
- カードの `id` は範囲の中で重複させない（進捗の記録に使う）

## 注意

- 学習用の教材データのみを置く。個人が特定できる情報は入れない
- ゲームの画像・音楽などの素材は使っていない（絵文字とCSSのみ）
